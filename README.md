## 🚀 Featured Projects

### 🛢️ Oil Forecasting: AI-Powered Price Prediction System

An end-to-end ML system that predicts oil prices using dual-model architecture combining NLP sentiment analysis with LSTM time-series forecasting.

**Tech Stack:** Python • FastAPI • PyTorch • Transformers • Apache Airflow • PostgreSQL • Docker • Terraform • AWS SageMaker

**Key Highlights:**
- 🤖 **Custom FinBERT Model**: Fine-tuned BERT-based sentiment classifier on 1,000+ oil market headlines (95% accuracy)
- 📊 **LSTM Forecasting**: Multi-layer time-series model using sentiment scores as exogenous variables
- ⚙️ **Production Pipeline**: Airflow orchestration for daily inference and monthly retraining
- 🔐 **RESTful API**: JWT-authenticated endpoints for metrics, chat completions, and predictions
- ☁️ **Infrastructure as Code**: Terraform modules for AWS deployment (SageMaker, ECR, VPC)

**Architecture:**
```
[News Headlines] → [FinBERT Sentiment] → [Feature Engineering] → [LSTM] → [Oil Price Prediction]
                                                ↓
                                [Airflow Orchestration + FastAPI]
```

The system analyzes geopolitical events, economic indicators, and market disruptions to generate sentiment scores that enhance traditional time-series forecasting.
